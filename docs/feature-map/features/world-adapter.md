# World Adapter 与 MOM 工作台 Feature Map

设计待实施。现有路径见 [MOM Feature Map](mom.md)，目标见 [UI/UE 与计划](../../mom/WORLD_ADAPTER_PLAN.md)、[协议与特性清单](../../mom/WORLD_ADAPTER.md)。表中 E2E-WA 编号待登记，控件名作为未来 Playwright 定位契约。

| 拟用例 | 操作路径与定位 | UI 和业务断言 | 追溯 |
|---|---|---|---|
| E2E-WA-01 世界绑定 | 「MOM 工作台」→「选择世界」→「看板」「任务」「资源」分别打开同一事项 | 同一 world/case 和版本；返回保持筛选；跨世界请求拒绝 | WA-01、08 / UI01、02、16 / P-MOM-ENTRY、SCOPE、RETURN |
| E2E-WA-02 续读 | 「看板」断线，重连或点「重新读取」 | 从提交边界补事件，同 ID 只应用一次；过期和水位单独显示 | WA-02、07 / UI03、15 |
| E2E-WA-03 条件 | 「任务」→「受阻」→「刀具调拨」，从「资源」→「料」再次定位 | 受理后待实物交接，首件未通过不能放行；冲突引用同一资源并无重复预留 | WA-08 / UI03、05、06、11 / P-MOM-STATE、VIEWS |
| E2E-WA-04 节点和来源 | 「处理进展」→「维护初筛」→「证据与记录」「通俗解释」，打开「流程选择依据」 | 一次点击可见结论，候选假设仍待验证，草稿流程不可执行，证据来源可查 | WA-07、08 / UI04、07、08、15 |
| E2E-WA-05 审批 | 「方案与决定」→「前往运营频道」→同案例卡「批准」；模拟同时修改版本 | 展示冲突，旧授权零写入。对象、范围、前置条件与修订可核对 | WA-03 / UI07、09 |
| E2E-WA-06 恢复 | 「执行已批准动作」→「查看执行」→「查证结果」 | 重试只执行一次；部分成功可区分；取消后无额外写，迟到回执不改变终态 | WA-04 / UI10、15 |
| E2E-WA-07 动态 DES | 会话进入动态 DES → 批准维修 → 推进 →「核验证据」 | 已投递历史不变，未来事件因干预改变，评测答案匹配；普通用户无答案；失联可诊断 | WA-05、07、08 / UI07、14、15 / RT-DES-08～11、RT-DESC |
| E2E-WA-08 会话和小屏 | 「与 AI 讨论」写 A 草稿 → 切 C → 回 A；节点证据页按 Escape | 草稿和上下文隔离，焦点恢复，小屏无横溢，模型离线时已有证据可查 | WA-07、08 / UI12、16 / P-MOM-CONTEXT |
| E2E-WA-09 客诉与移交 | C101 →「承诺与交接」→检查冻结、回复、8D 与接责 | 缺依据不能关闭。4 小时回复、24 小时报告与关闭各自验证。移交保留风险 | WA-08 / UI13、14 |
| E2E-WA-10 生产确认 | 选择生产世界 → 资产来源及水位 →「创建维修工单」→批准→「查证结果」 | 按工单号核对站点、设备与状态。延迟显示待查证。工单记录和设备恢复分开 | WA-06、07 / UI02、09、10、15 |

Playwright 先用 Harness 装载场景和时钟，再从产品首页开始。以拥有明确名称的导航、事项区、对话框或频道卡限定定位范围。重复业务动作使用案例或执行 ID 定位，例如在对应 OpsCase 内定位角色 button 和精确名称「批准」。故障准备可以调用测试入口，正常操作经 UI。通过正常业务 API 核对副作用和版本。

正式验证矩阵随实施登记到 features.json、CASES.md、COVERAGE.md。各用例绑定其适用的 Mock、远程 DES 和站点环境。原型证据见 [浏览器运行记录](../../mom/prototype/TEST_RESULTS.md)，协议目标用例当前待实现。
