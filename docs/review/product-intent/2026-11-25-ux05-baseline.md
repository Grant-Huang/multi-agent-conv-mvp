| 项目 | 内容 |
|---|---|
| 旅程 | [UX-05 主动提醒 → 稍后处理 → 回来处理](../../experience-map/journeys/UX-05.md) |
| 角色 | [P-SUP-NEW 生产主管 · 第一次使用](../../experience-map/personas/P-SUP-NEW.md) |
| 被审版本 | `master` 的 `5fd2dac`，本地 e2e 测试环境（`desktop.test_fixtures=true`，模型为本地模拟服务） |
| 依据 | [PRODUCT.md](../../PRODUCT.md) v1.4 的 CH-U2、CH-U3；CH-U7（v1.5，#320 待合并，用户已确认）；[ai-desktop/DESIGN.md](../../ai-desktop/DESIGN.md) 第 7 节 |
| 方式 | 探索式审查 3 条路线（1440 宽）；确定性用例 E2E-UX05（连跑 3 次通过）；CH-U7 布局探针（4 个宽度） |
| 审查者 | Claude Code 会话（非盲测） |

## 1. 结论

- **CH-U3 部分成立**：提醒以浮层出现，不抢输入焦点；关联任务的提醒在“为你关注”里能直达任务，处理完返回提醒仍在（E2E-UX05）。
- **CH-U3 不成立的部分**：新提醒到达时“为你关注”不更新，要刷新才能点到（**高**）；没有“稍后”，唯一动作“忽略”会让提醒从“为你关注”彻底消失（中）；助理消息只能“标记已读”，点不进对应的事（中）。
- **CH-U7（新条款）部分成立**：页面本身不滚动、会话页输入框固定已成立；首页与工作区输入框随内容滚动（**高**）。

## 2. 路线

| 路线 | 做法 | 结果 |
|---|---|---|
| A | 桌面打开后经测试接口注入一条关联 SMT-03 的普通提醒 | 浮层出现“建议：复核 SMT-03 证据 / 忽略 / 静音普通建议”；“为你关注”**不变**；刷新桌面后“为你关注”才出现该提醒（含“查看证据”） |
| B | 浮层点“忽略”，再刷新桌面 | 同一会话内“为你关注”的卡片仍在；刷新后卡片消失。没有“稍后”“打开”“追问”“反馈”，不显示原因与来源 |
| C | 不忽略；从“为你关注”点该提醒 → 返回桌面 | 进入 SMT-03 工作区；返回后提醒仍在“为你关注” |

另：右侧“助理消息”三条（建议关注 · 证据缺口、紧急 · 产线联锁提醒、今日摘要）每条只有“标记已读”，点不进对应的任务或对象。

## 3. 发现

### INTENT-2026-023　“为你关注”不随新提醒实时更新（高）

- **违反**：CH-U3（把重要的推到面前）。
- **证据**：路线 A；`web/src/desktop/DesktopHome.tsx` 第 91～101 行，快照 `load` 只在挂载时调用。浮层由轮询更新，两处不同步。
- **派工**：第 1 线 [#322](https://github.com/Grant-Huang/multi-agent-conv-mvp/issues/322)（UXFIX-N）。

### INTENT-2026-021　没有“稍后”，“忽略”让提醒彻底消失（中）

- **违反**：CH-U3（用户能调节）；DESIGN 第 7 节“可追问、稍后、忽略、静音或反馈”“展示原因、来源、关联 Task、优先级和可操作入口”。
- **证据**：路线 B；`web/src/desktop/AttentionToast.tsx` 只有“忽略”与“静音普通建议”。
- **派工**：第 1 线 #322（与 023 同卡）。

### INTENT-2026-022　助理消息不能直达对应的事（中）

- **违反**：CH-U3（有行动价值）；与 INTENT-2026-006（紧急事项只在侧栏）同源。
- **证据**：右侧“助理消息”每条只有“标记已读”。
- **派工**：并入第 1 线 [#306](https://github.com/Grant-Huang/multi-agent-conv-mvp/issues/306)（UXFIX-G 助理面板）补充范围。

### INTENT-2026-020　首页与工作区对话输入框随内容滚动（高，CH-U7）

- **违反**：CH-U7（约束：对话输入框不随内容滚走）。
- **证据**：布局探针（把可滚动栏滚到底，测输入框位置）：

| 宽度 | 页面本身滚动 | 首页 S1 输入框 | 工作区输入框 | 会话页输入框 |
|---|---|---|---|---|
| 1440×900 | 否 | 内容不足一屏，未触发 | 未触发 | 固定 |
| 1024×700 | 否 | 未触发 | 未触发 | 固定 |
| 768×600 | 否 | 135→131px | 407→241px | — |
| 390×844 | 否 | 135→89px | 754→388px | — |

  首页输入框在 `.desktop-home`（`styles.css` 第 505 行）、工作区输入框在 `.workspace-session`（第 663 行）这两个整栏滚动容器内；会话页消息区 `.messages`（第 118 行）单独滚动、输入框在外。
- **派工**：第 1 线 [#321](https://github.com/Grant-Huang/multi-agent-conv-mvp/issues/321)（UXFIX-M，与 #308 窄屏输入框衔接）。

### 符合项

- 提醒浮层不抢焦点（与 E2E-ADATTN 一致）；静音普通建议可用。
- 从“为你关注”进入任务再返回，提醒保留（CH-U2）。

## 4. 局限

- 非盲测；提醒经测试接口注入，真实提醒的来源、去重和频控未覆盖。
- UX-05 只跑 1440 宽；CH-U7 探针覆盖 4 个宽度，但 1440、1024 下夹具内容不足以触发溢出。
