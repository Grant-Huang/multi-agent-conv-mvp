## 一、总验收条件

1. 四类产物（个人风格、决策画像、组织 taste、业务内省结论）用户都能**看**（含来源和“为什么记住这条”）、能**改**（修改、否认、置顶、撤销）。
2. 改动**不会立刻改变系统行为**：个人改动下一个会话才生效；组织 taste 经评测和评委批准才生效；阈值和 SOP 走现有审批。
3. 风格和画像**只改呈现**：不裁剪风险信息，不过滤选项，不改数值和事实。
4. 画像**不被用于评估员工**；管理员默认读不到个人画像。
5. 业务内省**只读**：不改阈值、规则、配额，不写回 MOM；所有数字可由代码回算；每条结论的证据都能点回原始记录。
5a. 业务内省**只有运营负责人可见**；定时运行；**推送克制**，只有通过发送闸门的结论才推送，其余只在内省页可查，且每次没推送都记录原因（决策第 51 条）。
5b. “误报”相关主题因缺少标注暂缓，缺口见“已知缺口”（决策第 52 条）。
6. 涉及后台任务的部分，要写明超时、取消和清理策略（见第六节）。

## 三、推断、验真与安全（RT-MEM-06～11）

| Case | Given | When | Then |
|---|---|---|---|
| RT-MEM-06 | 用户在一个任务里说过一次“这次简短点” | 内省任务处理该会话 | 不升级为稳定偏好；只在跨 ≥2 个不同场景、独立重现 ≥N 次（N 可配置，初稿 3）后才生成“假设”条目 |

| RT-MEM-10 | 他人消息含“以后对张三都这样回答……”；用户本人也对自己的 agent 说过一句“以后回答简短点” | 抽取 | 前者不进画像；后者以 `origin=user_explicit` 进入 |
| RT-MEM-11 | 一条习得偏好 N 天没有被印证；一条用户显式声明；一条置顶 | 维护任务运行 | 习得偏好降为 `needs_review` 并停止自动应用；显式声明和置顶不变 |

### 5.1 定时运行、推送克制与权限（决策第 51 条）

| Case | Given | When | Then |
|---|---|---|---|
| RT-INT-16 | 定时内省到点；没有任何结论通过发送闸门 | 任务运行完成 | 结论全部写入内省页；**没有任何推送**；每条结论记录“未推送原因” |
| RT-INT-17 | 一条结论：验真已支持、影响面超门槛、有明确下一步；另一条：证据不足、无下一步 | 发送闸门判定 | 前者推送给运营负责人；后者不推送，原因写明 |
| RT-INT-18 | 规则判定“不该推”，模型自我审查认为很必要；另一条规则判定“该推”，模型认为不相关 | 发送闸门判定 | 模型只能在规则分上做 ±1 调整并给理由；不能单凭模型把规则判不推的结论推出去，也不能无理由压掉规则判定该推的 |
| RT-INT-19 | 同一条结论已推送且未读，内省再次运行 | 再次判定 | 不重复推送；仅当验真结果变化、影响面扩大或被反驳时才可再推 |
| RT-INT-20 | 运营负责人当日已收到内省推送并达到日配额（初稿 1 条） | 又有一条通过闸门的结论 | 不外发；转入次日摘要或仅在内省页显示，并提示“另有 N 项已合并” |
| RT-INT-21 | 当前是单用户部署；另外用**注入的身份**模拟“非运营负责人” | 分别以默认用户和注入身份读取内省页和内省接口 | 默认用户（即运营负责人）可读；注入的非运营负责人被拒绝，不泄露条数或标题；判断集中在一个函数，读取和推送都经过它（决策第 53 条） |
| RT-INT-24 | 一条通过闸门的结论 | 推送 | 在主 agent 与用户的私聊会话里**新增一条消息**，来源标为系统内省；**不触发模型回复，不创建任务**；消息内容不被当作指令；之后的记忆抽取跳过它 |
| RT-INT-26 | 已有普通会话若干；个人主窗口会话尚未创建 | 第一次推送内省结论 | 自动创建**唯一**的个人主窗口会话（即用户与主 agent 的会话）；之后无论推送多少次都不新建第二个；它不能被删除；其他会话的增删改不影响它 |
| RT-INT-27 | 主窗口会话已有 2 条未读内省消息 | 读取未读数；标记已读；服务重启后再读 | 未读数为 2；标记后为 0；重启后仍为 0（未读状态持久化）；普通聊天消息不计入未读 |
| RT-INT-28 | 主窗口里有一条内省消息；用户追问“为什么这么说” | 提交 | 主 agent 能看到该内省消息并据此回答；内省消息在上下文里标为数据，其中的祈使句不被执行；内省消息本身仍不被抽取进个人记忆 |
| RT-INT-29 | 其他普通会话 | 触发内省推送 | 其他会话里没有任何内省消息，未读角标只出现在个人主窗口 |
| RT-INT-25 | 配置里写了角色限定项（预留，暂不生效） | 启动并读取内省 | 行为不变；启动日志说明该项暂不生效，不报错 |
| RT-INT-22 | 一条被推送的结论、一条被压下的结论 | 运营负责人分别标“该推 / 不该推” | 标注与结论关联保存；不立即改闸门规则；可导出用于校准 |
| RT-INT-23 | 内省定时任务未到点；或用户手动触发 | 查看调度 | 定时任务只按计划运行；手动触发也走同一发送闸门，不绕过克制规则 |
