# 共享契约：身份与审批（草案）

| 项目 | 内容 |
|---|---|
| 状态 | 草案，待用户确认 |
| 核对基线 | 远端 `master` 的 `34fb1ab`（2026-11-21） |
| 适用特性 | 任务审批、助手配置确认、Agent 准入、MOM 案例批准、运营频道批准、AI 桌面审批与证据权限、World Adapter 执行、业务内省权限 |

## 1. 范围

所有“需要人同意才能继续”的动作，以及所有“按人决定能不能看、能不能做”的检查。

## 2. 现状

目前没有登录。各特性各自处理身份和批准：

| 特性 | 现在怎么认人 | 现在怎么批准 | 位置 |
|---|---|---|---|
| 任务审批 | 不认人；只监听本机，加 Host 校验 | `POST /api/tasks/{id}/approve`，不记录批准人 | `crates/server/src/lib.rs`；DESIGN 第 13.1 节 |
| 助手配置 | 不认人 | 一次性确认凭证（10 分钟） | DECISIONS 第 1、9 条 |
| Agent 准入 | 不认人 | `approver` 是任意字符串 | 台账 R-20261110-M1 |
| MOM / 运营频道 | 固定夹具身份 `supervisor` | 卡片带 `scope`、`plan_revision`，重复点击幂等，方案过期回 409 | 决定 60；[mom/WORLD_ADAPTER.md](../mom/WORLD_ADAPTER.md) 第 2 节 |
| AI 桌面证据 | 夹具请求头 `x-desktop-principal`（缺省 `alice`） | 证据按授权读取，无授权回 403 | 决定 69 |
| 业务内省 | `is_operator` 恒为真，测试可注入拒绝 | — | PLAN「INT」S5 |

## 3. 已确认的不变量

| # | 不变量 | 来源 |
|---|---|---|
| A1 | 一次批准绑定**操作者、动作参数版本和有效期**；参数变化、过期或权限撤回都必须重新确认；拒绝和超时阻止继续执行 | [ai-desktop/DESIGN.md](../ai-desktop/DESIGN.md) 第 6 节 |
| A2 | 审批界面展示的内容就是被批准的内容：按服务端保存的提案展示；动作内容或前置条件变了就生成新提案、重新审批 | [mom/WORLD_ADAPTER.md](../mom/WORLD_ADAPTER.md) 第 4.3 节 |
| A3 | 同一批准只能消费一次；重复提交按幂等键返回原结果，不重复执行 | WORLD_ADAPTER 第 4.4 节；决定 60 |
| A4 | 能力列表只用于发现，服务端每次重新验证授权 | WORLD_ADAPTER 第 3 节 |
| A5 | 会话 agent 只能观察、续读、形成方案和查看结果；审批决定由人从授权入口作出 | WORLD_ADAPTER 第 3 节 |
| A6 | 开放生产写入前，必须完成生产身份和角色映射；生产授权额外绑定实际操作者和职责范围 | WORLD_ADAPTER 第 1、4.4 节 |
| A7 | 查询、引用、通知、检索和执行都按服务端认证的身份与授权范围过滤；权限撤回后清理相应缓存和预览 | ai-desktop/DESIGN 第 5 节 |

## 4. 建议补充的不变量（助手建议，待确认）

| # | 不变量 | 理由 |
|---|---|---|
| B1 | **人的操作凭证与 agent 隔离**：批准、配置确认、准入审批、业务写批准只接受浏览器会话持有的凭证（例如 HttpOnly cookie 加 Origin 校验），系统启动的子进程拿不到 | 只监听本机不等于调用方可信；执行中的 agent 有 shell 权限，可以调用本机接口（2026-11-21 设计评审 D3，推断未复现；同类台账 R-20261119-M5、R-20261110-M1） |
| B2 | 每次批准都记录批准人、时间、批准的内容摘要 | 现在任务审批和准入审批都不记录批准人 |
| B3 | 所有批准走同一个模型（A1～A3），不同特性只是不同的动作类型 | 现在任务、MOM、桌面三处各有一套 |
| B4 | 没有真实身份前，夹具身份在界面和记录里标明“测试身份” | 与宪章原则 8（真实与模拟可辨）一致 |
