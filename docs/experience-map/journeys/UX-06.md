# UX-06：从工作中直达对应设置，改完回到原处

| 项目 | 内容 |
|---|---|
| 角色 | [P-SUP-NEW 生产主管 · 第一次使用](../personas/P-SUP-NEW.md) |
| 守护的宪章条款 | CH-U2 保护工作连续性；CH-U4 复杂度按需展开（配置退到幕后，只有一处、容易找到）；CH-U5 用户不需要理解系统内部 |

| 确定性用例 | E2E-UX06（`web/e2e/experience.spec.ts`） |

## 目标与成功标准（探索式审查只拿到这一节）

- **目标**：正在 SMT-03 调查里写草稿时，觉得 AI 的说话方式不合适，想顺手调一下助理的设置；或者被提醒打扰太多，想改提醒方式。改完接着写调查。
- **成功标准**：在当前工作里就能找到对应设置，不用去菜单里翻；改完立刻生效；回去时还在原来的任务里，草稿还在；设置项看得懂。
- **起始状态**：首页已有 SMT-03（夹具数据，标“模拟”）。

## 约束（必须成立）

| 编号 | 约束 | 宪章 | 用例 |
|---|---|---|---|
| UX-06-I1 | 场景内设置捷径直达对应分类，而不是设置首页 | CH-U4 | E2E-UX06 |
| UX-06-I2 | 保存后改动在桌面各处生效 | CH-U4 | E2E-UX06 |
| UX-06-I3 | 关闭设置回到原工作区，任务与草稿不变 | CH-U2 | E2E-UX06 |
| UX-06-I4 | 从分类进入子层（记忆），返回回到原分类 | CH-U2 | E2E-UX06 |
| UX-06-I5 | 从场景捷径进入设置后，一次返回即回原工作 | CH-U2 | E2E-UX06-I5（UXFIX-O 修复） |
| UX-06-I6 | 从提醒可直达对应设置（通知与主动性） | CH-U4 | **欠账**：“通知与主动性”为占位，见 INTENT-2026-025；#309 补充范围 |
| UX-06-I7 | 设置用用户语言，不显示内部概念与测试控件 | CH-U5 | **欠账**：Soul / Taste 与“注入冲突（测试）”，见 INTENT-2026-012、003；#306、#305 |
