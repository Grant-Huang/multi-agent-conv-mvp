## 4. 每周更新方式

周五周检时：复核第 1、2 节状态并附证据；有新的、有证据的缺口才加行；第 3 节保持最多 3 项在做，完成的移到“之后”或删除；可以提出删除重复或无效的检查。改动走一个治理 PR，同时更新 [GUARDRAIL_REGISTRY.yaml](GUARDRAIL_REGISTRY.yaml)。
