## 怎么写

- **文件名**：`YYYY-MM-DD-主题.md`，主题用小写英文和连字符，例如 `2026-11-21-doc-layers.md`。同一天同主题再加后缀 `-2`。
- **引用**：写文件名（不带 `.md` 也可），例如“决定 2026-11-21-doc-layers”。
- **开头表格**：日期、来源（用户确认 / 用户采纳 / 助手建议 / 实验数据结论，含义同 `DECISIONS.md`）、状态（有效 / 已取代 / 待用户确认）、相关文档。
- **正文**沿用 `DECISIONS.md` 的五项：问题、定了什么、为什么、没选什么、出问题先看。
- **被推翻时**：不删文件，把状态改成“已取代”，写明被哪个文件取代。
- 没得到用户明确表态的，来源写“助手建议”，不能当成已确认。
