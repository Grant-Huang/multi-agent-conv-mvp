**一句话结论**：凭据引用形态 = **env 优先**（[llm] `api_key_env` 已随 #493 落地，keychain 作为后续增强另卡）；未注册外部系统 = **迁移期先告警、期满翻转拒绝**（翻转时点随一个里程碑由用户拍板）；描述符存放 = **统一 `connectors.toml`**（各面现有配置保持不动但引用描述符 id）。

## 背景

连接器契约草案（#477 批准生效）遗留三个待决定项（§7），是迁移卡 #486（agent 命令定位）与 #487（mom_relos 入注册）的实现前置。

## 定了什么

| 待决定项 | 拍板 | 落地 |
|---|---|---|
| ① 凭据引用形态 | **env 优先**：`credentials = { env = "X" }` / `[llm] api_key_env`；keychain 作为后续增强**另卡**（env 已覆盖两处实现） | PR #493（[llm] api_key_env）已落地；[backends.*] 既有口径不变 |
| ② 未注册外部系统阻断时机 | **先告警后拒绝**：迁移期发现未注册直连只记 WARN（`connector.unregistered`），运行不受影响；迁移期满翻转「未注册 → 拒绝调用」，翻转时点随一个里程碑由用户拍板 | an-mom 的 relos 装配按此实现（#487）：未注册 → WARN + 回退旧配置 |
| ③ 连接器描述符存放 | **统一 `connectors.toml`**：所有连接器描述符一处可查（发现 / 健康 / 凭据引用）；各面现有配置保持不动但引用描述符 id；审计与迁移清单直接对着它 | #487 实现：`an_runtime::connectors` 注册表 + 默认路径 `connectors.toml`（`CONNECTORS_TOML` 可覆盖） |

**子决定**：字段 `credentials.env` 未设置时——服务不需要鉴权即无凭据调用；需要鉴权而 env 缺失则 WARN（`connector.credential_missing`）并不带凭据调用（RelOS 现状未启用鉴权，不阻断）。

## 出问题先看

- 忘了给某连接器配 env：日志搜 `connector.credential_missing`。
- 迁移期满忘了翻转：契约 §6 迁移清单全部完成后在里程碑清单里明确翻转时点。
