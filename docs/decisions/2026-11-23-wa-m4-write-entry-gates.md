## 背景

M3 已在桩数据路径准出生产只读（#228）。PLAN / WORLD_ADAPTER_PLAN 的 M4 行要求真实审批、MES 维修工单与候选站点验收。若直接做「生产写首刀」实现，会在站点与身份未就绪时绕过合同与安全边界。

## 定了什么

1. M4-0 只交付任务卡 + 准入清单 + 边界文档（本决定）。
2. 准入门槛见 [WA_M4_TASKS.md](../mom/WA_M4_TASKS.md) §1（G1～G8）；G4「候选站只读全浏览器路径」为写实现前置，单列为 **M4-1**，须另授权。
3. 未满足门槛前：**禁止**去掉/弱化 `WRITE_DISABLED`；**禁止**合入生产世界可写实现；不改 `store` / `orchestrator` 作写落地。
4. 首个写动作仍建议 `create_maintenance_order`（设计原文）；实现排在准入齐 + M4-2 方案批之后。

## 没选什么

- 不选「先在桩上假装生产写再换真站」作为准出路径。
- 不选本卡顺手改业务代码或开 M4-1。
