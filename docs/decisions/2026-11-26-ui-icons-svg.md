# 界面用简洁 SVG 图标代替可表意的文字，不用 emoji；审查时双向检查界面

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-26 |
| 来源 | 用户确认（2026-11-26 对话：“为节省空间，适当使用能够表意的图标代替文字，图标用简洁的 svg 样式的图标，拒绝用 emoji 类型的图标”；“审查的时候，既要看每个界面应该有的特性或功能有没有，还要看不应该有的功能特性出现在不合适的位置”）；实施细则（无障碍名称、哪些保留文字）为助手建议 |
| 状态 | 有效 |
| 影响范围 | AI 桌面全部界面（第 1 线实现，见派工 Issue）；产品意图审查与每周守护者的检查项（[GUARDIAN.md](../experience-map/GUARDIAN.md) 第 2 节第 1 步第 4 条、[体验地图 README](../experience-map/README.md) 第 3 节） |
| 相关设计 | [ai-desktop/DESIGN.md](../ai-desktop/DESIGN.md) 第 2 节（使用原生可聚焦控件、支持键盘）；宪章 [PRODUCT.md](../PRODUCT.md) CH-U4、CH-U5、CH-U7 |

**一句话结论**：界面上能用图标表意的控件，用统一风格的简洁 SVG 线性图标代替或配合文字，节省空间；不用 emoji，也不用字符符号（如 ⚠ ✓ ✗ ☰ ◇ ▾）充当图标；每个图标都要有无障碍名称。审查时对每个界面双向检查：该有的有没有，不该有的有没有出现在不合适的位置。

## 背景

宪章 v1.5 的 CH-U7 要求桌面本身不滚动、各栏按需滚动，界面空间更紧；首页、工作区、会话页的工具条大量使用文字按钮（如“设置与管理”“返回桌面”“专注 S3”“分屏 S2”）。体验地图 UX-01～UX-07 的审查只检查了“该有的功能是否可用”，对“不该有的东西出现在哪里”没有成文的检查项，但实际发现中有不少属于这一类（INTENT-003 测试控件、INTENT-018 旧四页签残留、INTENT-029 英文状态码）。

## 问题

- 文字按钮占空间，挤压工作区与对话区。
- 现有符号图标是字体字符，平台不同显示不一（`⚠` U+26A0 在部分系统按 emoji 渲染），风格也不统一。
- 审查方法缺少“不该出现”的检查维度，容易漏掉整治残留。

## 决策依据

1. 用户 2026-11-26 的两条要求（见“来源”）。
2. 代码事实（2026-11-26 扫描 `web/src`，排除测试文件）：仓库没有图标组件，也没有 `<svg>` 图标；界面里用作图标的字符有 `☰`（`App.tsx:629`）、`⚠`（`components/AgentCards.tsx:211`）、`✓` `✗`（`components/AgentCards.tsx:287`）、`◇`（`desktop/profileStore.ts:25` 助理默认头像）、`▾` `▴`（`App.tsx:961`、`components/TaskTicker.tsx:30`）、`←`（`desktop/DesExperiment.tsx:228`、`desktop/MomWorkbench.tsx:350`）。
3. 审查记录：INTENT-2026-003、018、029 都属于“不该有的出现在不合适的位置”（见 `docs/review/product-intent/` 各基线报告）。

## 定了什么

### 图标

| 规则 | 说明 |
|---|---|
| 用 SVG 线性图标 | 统一一套简洁线性风格（单色、描边、随文字颜色与主题变化），以组件方式内联，不引入 emoji 或图标字体 |
| 不用 emoji、不用字符符号当图标 | 现有 `☰ ⚠ ✓ ✗ ◇ ▾ ▴ ←` 等替换为 SVG |
| 适当替换，不是全部替换 | 含义通用的动作（返回、关闭、设置、展开 / 收起、搜索、发送、证据、专注 / 分屏布局、状态成功 / 失败 / 警告）优先用图标；含义不通用或首次出现的业务动作（如“批准”“在频道中处理”）保留文字或用“图标 + 文字” |
| 无障碍 | 只有图标的按钮必须有无障碍名称（`aria-label`）和悬停提示；现有 E2E 按可见名称定位的，无障碍名称保持原文字，测试不需改断言 |
| 记录到设计 | 第 1 线在 `docs/ai-desktop/DESIGN.md` 写明图标清单与使用规则 |

### 审查

- 每个界面双向检查：该有的特性和功能是否都在、可用；不该有的功能、控件、术语或数据（测试控件、开发诊断、内部 ID、英文状态码、与角色无关的功能、重复入口、整治后的残留）是否出现在不合适的位置。
- 用 emoji 或字符符号当图标，记为偏离。
- 已写入 [GUARDIAN.md](../experience-map/GUARDIAN.md) 第 2 节第 1 步第 4 条与 [体验地图 README](../experience-map/README.md) 第 3 节。

## 没选什么

| 做法 | 为什么没选 |
|---|---|
| 写进宪章 | 用户没有要求；属于界面设计层规则，可以替换（宪章只写意图）。如需升为宪章条款，另行确认 |
| 全部按钮只留图标 | 业务动作图标难以表意，第一次使用的用户看不懂（CH-U5）；用户也说“适当使用” |
| 用 emoji 或图标字体 | 用户明确拒绝 emoji；图标字体依赖外部字体，渲染不稳定 |
