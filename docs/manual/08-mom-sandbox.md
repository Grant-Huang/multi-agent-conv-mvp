# 08 MOM 运营沙盘（制造运营仿真）

> **这是模拟环境。** 所有业务系统（MES/QMS/EAM/WMS）、主 Agent 决策、专业调查、审批身份、车间 DES 参数都是替代件，清单见 [MOCK_REGISTER](../mom/MOCK_REGISTER.md)。用它体验“事件进来 → 人审批 → 执行 → 核验 → 关闭”的控制链，**不能据此判断真实工厂的诊断或排产是否正确**。

## 入口

| 方式 | 地址 | 说明 |
|---|---|---|
| 主界面入口 | 左侧栏“**MOM 运营沙盘**” → `/mom/` | 同源，仅在 loopback 主服务上挂载 |
| 独立服务 | `cargo run --bin an-mom` → <http://127.0.0.1:8790> | `--db data/mom.db`、`--bind`（必须是回环地址）、`--llm-config config.toml`、`--relos-url http://host:port` |

页面标题“MOM 运营公告板”，有两种视图切换：**人类运营视图**（态势、决策、回执、缺口）和 **Agent 机器视图**（给 Agent 读的 JSON）。

## 场景 A：产线异常 S1（多扰动）——审批后下发，核验再关闭

1. 点“＋ 多扰动 S1”，案例状态出现 `WAITING_HUMAN`，页面显示涉及设备（如 `CNC-XX`）。
2. 切到“Agent 机器视图”：看到分页游标 `next_cursor` 与安全约束（如 “Never bypass safety”）。
3. 切回“人类运营视图”，点“**批准**”。页面记下审批人（如 `supervisor`）。
4. 点“**执行已批准动作**”→ 案例进入 `VERIFYING`。
5. 点“**推进 5 分钟**”（虚拟时钟）→ 出现核验证据（如 `mock-verification`）。
6. 点“**核验并关闭案例**”→ `CLOSED`。

要点：**没批准不会下发；没核验证据不能关闭。** 设备安全联锁触发时，通过 HTTP 直接 PATCH/下发也会被拒绝且无副作用。

## 场景 B：客户投诉 S2——先初步回复，8D 缺证据不能关闭

1. 点“＋ 客诉 S2”，状态 `WAITING_HUMAN`；页面显示阶段 `INITIAL_RESPONSE`、根因 `UNKNOWN`、`PROGRESS_8D`。
2. 批准 → “执行已批准动作”→ 进入 `INVESTIGATING`，对客动作 `customer.send` 写入**模拟发件箱**（不会真实外发）。
3. 此时点“核验并关闭案例”会被拒绝，错误区显示 “verification incomplete”，案例不会关闭——**初步回复先于根因，8D 报告缺证据不能结案**。

## 场景 C：配置持续仿真（订单、种子、扰动持续出现）

1. 点“**配置持续仿真**”展开表单：订单数量、随机种子、持续事件数量、事件间隔（仿真分钟）。
2. 点“**创建配置仿真**”→ 案例进入 `COLLECTING`，列出 M01 等需要的真实系统接入缺口。
3. 反复点“推进 5 分钟”，排产方案与影响区显示与你配置相关的数值（如 `"quantity": 900`）。
4. 点“**播放 30 分钟**”自动播放，状态显示“播放中”；点“**暂停仿真**”显示“已暂停”。
5. 车间 DES 层按种子可复现（同一场景与种子得到同样的事件序列）。

## 场景 D：车间 DES（离散事件仿真）与协同事项

DES 模拟设备磨损、报警、刀具寿命、质量尺寸等因果过程，不需要单独入口，随案例运行：

- **开环**：事件一次生成后按虚拟时钟投递，处置不影响后续。
- **闭环**：选定方案并执行后会**回写仿真世界**（维修停机与复位、刀具调拨到达），核验证据来自执行后的同源观测。
- **协同事项**：同一产线 60 分钟内多个案例会合并为协同事项统一决策，关闭时级联；**安全联锁成员会被跳过并保留预留**，其余成员照常关闭。
- **审核层**：规则检查 + AI 审核（真实审核模型尚未接入，目前只给规则结果，接口返回 “no reviewer configured; rules only”）+ 人工确认；人工结论绑定当时的 AI 审核版本。
- **批量实验**：两种策略、同一组种子，导出 CSV。
- 大场景若无法满足约束，2 秒内返回 400，而不是卡住。

设计见 [DES_CLOSED_LOOP](../mom/DES_CLOSED_LOOP.md)。参数是建模假设，未用工厂样本标定。

## 场景 E：独立设计原型

`docs/mom/prototype/index.html`（及 `app.js`、`styles.css`）是 MOM 工作台 UI 的静态设计原型，用浏览器直接打开；检查脚本为同目录 `check*.cjs`。设计原则见 [UI_UX_PRINCIPLES](../mom/UI_UX_PRINCIPLES.md)。它不代表生产接口与权限集成。

## 状态词汇

| 状态 | 含义 |
|---|---|
| COLLECTING | 收集事件/数据 |
| WAITING_HUMAN | 等人审批或决策 |
| INVESTIGATING | 调查中 |
| VERIFYING | 执行后核验中 |
| CLOSED / CANCELLED | 终态；终态案例拒绝手动故障注入 |

## 边界

- 没有真实身份认证；审批人是测试身份。
- 没有墙钟生产调度、高可用。
- 配置了 RelOS（`--relos-url`）时，S1 诊断会读取其关系上下文；不可用时安全降级，知识仍是仿真数据。
