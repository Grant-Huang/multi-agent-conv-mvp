## 系统是什么

AgentNexus 是一个“对话 + 多 agent 执行”的最小可运行系统。你只和对话框说话；系统决定是直接回答，还是交给后台 agent 完成：

```
你 ──▶ 对话（直接回答 / 追问 / 委派 / 跟进已有任务）
          │ 委派
          ▼
       路由（选角色、估风险）──▶ 规则（角色可用？要审批？要审查？）
          ▼
   执行者：General（通用，内置，含文件/计算/联网工具）
           Coding（写代码，外部 agent）
           Reviewer（只读审查，判 pass / fail / needs_human）
          ▼
   审查不通过 → 带问题清单返工 → 生成交付消息 → 推送到页面
```

三条要记住的规则：

1. **完成不等于验收通过。** 代码、文档类任务要经过审查才算完成；进程正常退出不代表结果可用。
2. **高风险先问你。** 删除、对外发送、部署等任务会停在“待批准”，你点“批准执行”才会开始。
3. **出错如实报错。** agent 执行出错时直接显示错误，不会悄悄换别的 agent 重做。

## 安装与启动

前置：Rust 1.80+、Node 20+、一个 OpenAI 兼容的模型服务（默认本地 llama.cpp，`http://127.0.0.1:8098/v1`）；可选 Codex CLI 等外部 agent。

```bash
cp config.example.toml config.toml     # 按需改模型地址、工作目录
cd web && npm install && npm run build && cd ..
cargo run --release --bin agentnexus
```

浏览器打开 <http://127.0.0.1:8787>。

| 项 | 默认值 | 说明 |
|---|---|---|
| 主服务 | `127.0.0.1:8787` | `config.toml` 的 `[server].bind`；只接受 localhost / 127.0.0.1 / [::1] 的 Host |
| 数据库 | `data/agentnexus.db` | SQLite，会话、任务、事件都在里面 |
| 文件工具目录 | `workspace/files` | General 只能读写这里 |
| 代码目录 | `workspace/code` | Coding 在这里改代码，建议是独立 git 仓库 |
| 日志 | `logs/agentnexus.jsonl.<日期>` | JSON 行日志，见 [06 排查与反馈](06-troubleshooting.md) |
| 前端热更新 | `cd web && npm run dev` → <http://127.0.0.1:5173> | 后端照常运行 |

> 当前版本没有登录与多用户，只适合本机或可信局域网使用。

## 界面总览

页面分三栏：

| 区域 | 位置 | 内容 |
|---|---|---|
| 会话栏 | 左侧（窄屏点顶部“☰ 会话”打开抽屉） | “＋ 新会话”、“MOM 运营沙盘”链接、会话列表；**左下角是连接状态**：LLM 与每个 agent 一行 |
| 对话区 | 中间 | 消息、任务状态行、产物（查看/下载）、输入框“输入消息” |
| 状态栏 | 右侧 | 页签：任务 · 助手 · 节点（开发者模式下另有 诊断 · 路由日志）；底部“开发者模式：关/开” |

连接状态圆点含义：

| 圆点 | 含义 |
|---|---|
| 绿 | 已连通，可调用（握手成功，或 10 分钟内有成功调用）；内置 agent 始终为绿 |
| 灰 | 已配置但未连通 |
| 红 | 不可用（如命令不存在）。原因直接显示在该行或悬停提示里 |

任务状态的显示名：

| 显示 | 含义 |
|---|---|
| 已创建 / 排队中（第 N 位） | 刚建立 / 等执行者空闲 |
| 通用/编码执行中 | 正在执行 |
| 审查中 | Reviewer 在检查 |
| 待批准 | 高风险，等你点“批准执行” |
| 已完成 / 失败 / 已取消 | 终态 |

## 当前没有的能力

写在这里避免白找：多用户登录与鉴权、任务并行/通用动态 DAG、服务重启后断点续跑（中断的任务会标为失败）、跨互联网节点与节点 TLS、长期记忆、知识库、Slack 入口、生产级 MOM 连接器、自动 Bug 修复（Benny）。MOM 沙盘与 DES 全部是**模拟**，不连接真实业务系统。
