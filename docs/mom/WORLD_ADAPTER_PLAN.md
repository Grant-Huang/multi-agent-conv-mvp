# World Adapter 前端先行实施计划

依据 [WA-01～08](WORLD_ADAPTER.md#9-交付与验收)、[UI01～16](UI_UX_PRINCIPLES.md#14-场景验收基线) 和 [MOM 三入口原型](prototype/README.md)。采用 Lauren Tan 分享中的可操作 Feature Map，将入口、定位、操作、业务断言和证据绑定到同一用例。

本计划承接原 DES 阶段⑤「车间视图」、WP1 GS1 产品前门与运营桌面 D3（**DES-31，用户确认**）。入口拆分见 [DES 仿真实验与 MOM 运营入口](DES_EXPERIMENT_OPS_SPLIT.md)（**决定 62**）。DES 内核与⑤a 远程工厂基线不变，见 [DES_CLOSED_LOOP.md](DES_CLOSED_LOOP.md) §11b；系统打通总表见 [INTEGRATION_PLAN.md](../INTEGRATION_PLAN.md)。M0 执行卡见 [WA_M0_TASKS.md](WA_M0_TASKS.md)；M1 见 [WA_M1_TASKS.md](WA_M1_TASKS.md)；M2 见 [WA_M2_TASKS.md](WA_M2_TASKS.md)。

与 [AI Desktop V1.7 计划](../ai-desktop/PLAN.md) 的关系：AI Desktop 是产品壳与通用会话/任务前门；本计划覆盖其中 **DES 实验入口 + MOM/运营频道世界适配** 切片。两边共享「完整前端先行、每里程碑 Mock 可测、Mock 替换表、Feature Map + Playwright」硬约束；导航与壳层以 AI Desktop 为准，实验/运营业务路径以本文与 DES_EXPERIMENT_OPS_SPLIT 为准。

## 1. 目标 UI/UE

| 页面 | 用户操作与反馈 |
|---|---|
| DES 仿真实验 | 配置、试跑、正式运行、控制时钟和结果。正式运行指定运营频道，试跑只在实验页面预览 |
| AI 桌面运营频道 | 接收正式运行的业务事项，查看方案、审批与回执。消息卡标注仿真运行和下一步 |
| 世界和车间 | 从正常会话或运营入口选择世界。常驻展示当前世界、产线、模式和数据时间。断线时保留最近完整快照并可重新读取。切换隔离草稿、引用及游标 |
| 看板 | 事项卡显示影响、责任、时限、阶段和下一步。用六维影响标签筛选，通知不强制变成任务 |
| 任务 | 待办、进行中、受阻和已完成。默认展开受阻、折叠已完成。点击具体节点，状态区分受理、执行和核验 |
| 资源 | 人机料法环测摘要，缺口与全貌切换。点击刀具或检验缺口直达同一事项。受理后显示等待实物交接或检验 |
| 事项 | 概览、处理进展、所需条件、方案与决定、承诺与交接。已完成节点直接显示结论和证据。等待节点直达处置。返回恢复范围、筛选与滚动 |
| 方案和执行 | 方案页显示版本、动作、前提和影响。定位既有运营频道 OpsCase 卡审批。执行详情按维修、调拨、排产显示受理、已提交、已确认、失败或待查证，关闭前检查业务证据与接责 |
| AI | 单一入口，明确当前世界、事项和节点。桌面可调宽，手机切会话工作区。关闭恢复业务现场，模型故障时已有事实仍可读 |

真实来源、DES 与 Mock 在视图和记录级可辨。覆盖加载、空、过期、无权、离线和部分成功。键盘关键路径可用，手机无意外横向溢出。优先复用现有 React、运营频道和 MOM 状态投影。

## 2. 先快速搭建可运行的完整前端

1. 按原型与 [DES_EXPERIMENT_OPS_SPLIT](DES_EXPERIMENT_OPS_SPLIT.md) 冻结页面层级：`设置与管理 → DES 仿真实验`、`AI 桌面 → 运营频道`、三入口工作台、统一事项页、AI 与证据链；冻结可访问名称及状态文案。旧 `/mom/` 迁移期标为「MOM 仿真沙盘」。
2. 定义共享 DTO、错误、状态和服务端适配器边界。前端通过真实 HTTP 和事件接口操作，首版接服务端 Mock。Mock 使用可控时钟和独立临时持久库，覆盖试跑/正式运行、全部业务运行与异常状态。
3. 首批种子含 S1 插单、S2 客诉、多事项资源争用。可注入两身份（实验员/运营员）、两世界、过期、断线、重复事件、丢回执和部分失败。生产未接部分在独立模拟世界完成全路径。
4. 先实现可执行用例并看到业务 Red，再实现界面及 Mock。每阶段作为可部署版本交付，全量跑 Feature Map 对应的 Playwright 和集成回归（含 DES-UI-01～06）。所有可见入口有行为、返回路径及证据。

## 3. 交付里程碑

近期没有确定的工厂试点窗口。第 3 线沿用 M2-6 准出与 T-63 独立复验，维持远程 DES 回归。M3-2 桩数据服务层已合入。M3-3 已用桩数据验权限、续读、延迟和写关闭，M3-4 验浏览器路径。可并行准备候选站点、一个权威数据源和一类事件；站点及读权限落实后再安排真实只读验收。跨线汇合见[集成计划](../INTEGRATION_PLAN.md#五条研发线与近期汇合)。

| 阶段 | 实现工作 | 完整前端如何运行 | 准出条件 |
|---|---|---|---|
| M0 完整 React 前端＋协议 Mock | 完整实验入口与 AI 桌面运营链路，Mock 实现运行控制、五操作和消息投影 | 正常会话入口走浏览器 → HTTP → MOM → 服务端 Mock。生产路径也可在模拟世界操作 | 全部 WA 和 UI 断言映射到 Playwright 或后端集成。用例可独立重跑。S1、S2 与资源冲突全流程通过。DES-UI-01～06 的适用断言在 Mock 环境通过 |
| M1 远程 DES 读取 | 接主应用与现有连接器、真实创建与推进、世界绑定、MOM 快照及正式消息投递 | 远程 DES 可读；隔离 Mock 世界提供完整写入路径 | WA-01、02、07 的真实 DES 场景通过。全量 M0 回归 |
| M2 远程 DES 动作 | 串联方案、审批、待发任务、子动作回执、确认及答案同步 | DES 完整闭环，生产模拟仍可使用同一 UI | WA-03、04、05、08 在远程 DES 通过。RT-DES-08～11 和 RT-DESC 回归；动态场景证明未来事件改变，双角色在同一正式运行完成处置 |
| M3 生产只读 | 接站点权威源、水位、授权和事件断点恢复 | 真实站点观测可用，写入演示在独立模拟世界完成 | 生产读通过权限、延迟和多来源回归。M0～M2 全量回归 |
| M4 首个生产写动作 | 真实审批、MES 维修工单、关联号查询、人工对账 | 站点验收环境走完整浏览器链路 | WA-06 在候选站点通过。重复、未知结果、撤权等回归通过后才开放生产写动作 |

真实读和模拟写在产品中有清晰的模式标志。生产未接能力在独立模拟世界体验。同一交付使用同一前端、业务对象和测试流程，按部署注入适配器。

## 4. Mock 开发与替换

执行台账与可演示钩子见 [WA_MOCK_REGISTRY.md](WA_MOCK_REGISTRY.md)（H3）。下表为设计摘要。

| Mock | M0 行为 | 替换时机和验收 |
|---|---|---|
| 实验控制与消息 | 试跑和正式运行分别持久登记，支持时钟、重复启动与事项投递 | M1 替换运行与观察，校验正式投递和试跑隔离；M2 用真实仿真回执更新同一事项卡 |
| 世界与权限 | 两身份、两世界、跨范围拒绝、撤权和实例失效 | M1 接 DES 绑定，M3 接生产权限；列表、详情、计数、事件隔离合同相同 |
| 读与事件 | 一致快照、有序事件、可控分钟、游标过期、重复和断流 | M1 替换为 MOM 正式投递，M3 接多源水位；续读无漏、无重复业务应用 |
| 方案与批准 | 版本、硬约束、过期和角色。审批走原入口 | M2 复用 MOM，M4 接真实审批；过期批准产生零写入 |
| 写入、回执和取消 | 稳定执行 ID、逐子动作回执、丢失、部分失败及迟到回执 | M2 接 DES，M4 接 MES；重复执行、终态保护和权威证据契约通过 |
| 审核与诊断 | 假设、复检证据、模型不可用和仅审核侧可见的答案 | M2 接 DES 审核源；访问边界、证据来源和刷新失败恢复通过 |
| 生产来源 | 模拟 MES、ERP、设备系统及同步延迟，工单支持按关联号查证 | M3 替换读，M4 替换写；对账可复验，未支持动作关闭 |

Mock 服务与后端共用合同。故障和时钟控制仅在测试进程开放。每次替换先跑同一合同套件，再跑同一浏览器用例，逐动作切换并更新覆盖记录。退役产品模式的对应 Mock 路由，保留隔离 Mock 作持续回归。撤回真实写能力时暂停发送并保留对账记录。

## 5. 自动化与严格回归

- 以配套 [Feature Map](../feature-map/features/world-adapter.md) 登记正式 CASES、features.json 和 COVERAGE 条目。合入实现前检查所有 WA-01～08、UI01～16、DES-UI-01～06 均有可执行断言。测试入口用可访问 role/name 和实体键。
- 复用现有 Harness、Playwright 和 npm run test:map、npm run verify。为同套用例建立 Mock、远程 DES、站点验收项目，显式记录各项目覆盖能力。每里程碑全量执行已交付能力的回归，并执行剩余 Mock 路径。
- Playwright 经真实页面操作，检查反馈及正常 API 读取的 ID、版本、回执和副作用。独立集成测试穿透 HTTP、授权、存储、事件及适配器，覆盖无效批准、并发重试、超时查证、恢复和跨世界隔离。
- 报告记录提交、适配器、种子、浏览器、视口、通过断言、状态快照和回执。失败保留 Trace、截图和关联 ID。原型、Mock、远程 DES 和真实站点各自登记证据。新增断言先验证 Red；既有断言随适配器替换保持。
