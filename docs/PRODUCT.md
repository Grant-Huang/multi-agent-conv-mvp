## 1. 做什么

**面向制造业组织的 AI 工作桌面。** 人从同一个桌面入口提问、委派、取证、协作和审批；后台 agent 按确定的规则执行；业务动作经统一的世界访问契约作用到仿真工厂或真实工厂，走“观察 → 提方案 → 人批准 → 执行 → 核验”的受控闭环。

来源：决定 61（AI 桌面）、61（World Adapter）；2026-11-04 第一版设计的长期目标“组织级智能工作平台”（提交 `dd90a18` 的 `docs/DESIGN.md` 第 1.1 节）；2026-11-21 用户确认（[decisions/2026-11-21-design-overview.md](decisions/2026-11-21-design-overview.md)）。

## 3. 唯一主轴

1. **产品主轴只有 AI 桌面**，不做双轨，不再维护第二套一级导航。来源：决定 61（AI 桌面）。设计意图、依据和入口对照见 [decisions/2026-11-20-desktop-single-axis.md](decisions/2026-11-20-desktop-single-axis.md)。
2. **MOM、运营桌面、World Adapter 是桌面里的工业业务能力**，不是另一个产品：MOM 是案例、方案、审批和动作记录的唯一权威，但没有自己的产品界面；人从桌面的运营频道、运营模块和普通会话接触它，批准只在运营频道的案例卡上做；读写仿真或真实工厂只经 World Adapter。来源：2026-11-21 用户确认；决定 56～58、60、61（World Adapter）、62。设计意图、依据和结构见 [decisions/2026-11-21-industrial-capabilities-in-desktop.md](decisions/2026-11-21-industrial-capabilities-in-desktop.md)。
3. **2026-11-04 起实现的对话调度部件是执行引擎层的构件。** 来源：同上。
4. **必要的产品特性**：多 agent 执行与接入、业务内省、个人记忆、外发脱敏，以及 [DESIGN.md 第 0.3 节](DESIGN.md#03-产品特性设计索引) 登记的其他特性。来源：同上。
5. **新的主线或特性开工前，先在第 0.3 节登记，并写明为本文哪一条服务。** 来源：[decisions/2026-11-21-doc-layers.md](decisions/2026-11-21-doc-layers.md)。

## 4. 不做什么

| 不做 | 来源 |
|---|---|
| PLC / 现场联锁与设备闭环控制 | [mom/DESIGN.md](mom/DESIGN.md) 第 1 节 |
| 自动给客户发信、自动质量放行 | 同上 |
| 全厂排产求解器、完整通用 BPM 引擎 | 同上 |
| 无限递归的 agent、自动证明根因 | 同上 |
| 多 agent 自由群聊式协作 | [DESIGN.md](DESIGN.md) 第 2 节（不借鉴 AutoGen） |
| 桌面与旧界面双轨并行 | 决定 61（AI 桌面） |

人的批准不能绕过法定或工厂强制的安全约束（[mom/DESIGN.md](mom/DESIGN.md) 第 1 节）。

## 5. 不能破的原则

| # | 原则 | 来源 |
|---|---|---|
| 1 | **模型负责理解，程序负责决定。** 模型给的判断（如风险高低）只是建议；能不能执行、要不要审批、要不要质检由固定规则决定 | [DESIGN.md](DESIGN.md) 第 2 节；DECISIONS 第 1 条 |
| 2 | **用户只面对一个入口。** 执行的 agent 不直接跟用户说话 | DESIGN 第 2 节 |
| 3 | **出错就报错，不悄悄换人** | DESIGN 第 2 节 |
| 4 | **执行者不当自己的裁判。** 做完不等于做对，验收由独立一方和规则决定；Master 不批准自己 | DESIGN 第 1、2 节；[mom/DESIGN.md](mom/DESIGN.md) 第 2 节 |
| 5 | **状态由系统自己保存，每一步可追查** | DESIGN 第 2 节 |
| 6 | **业务事实归源系统。** 只有源系统受理并核验后，写动作才能标为完成；MOM 是案例、方案、审批和动作记录的权威来源 | mom/DESIGN 第 2 节；[mom/WORLD_ADAPTER.md](mom/WORLD_ADAPTER.md) 第 1 节 |
| 7 | **改配置、写业务这类有后果的动作，由固定代码执行，并要人确认**；模型不直接写业务状态 | DECISIONS 第 1 条；[mom/DESIGN.md](mom/DESIGN.md) 第 2 节（Master 不直接写数据库状态、不绕过工具网关） |
| 8 | **真实、仿真、模拟数据在界面和记录里始终可辨**，生产模式不静默回退到模拟 | 决定 61（AI 桌面）；[mom/WORLD_ADAPTER_PLAN.md](mom/WORLD_ADAPTER_PLAN.md) 第 1 节 |
| 9 | **完整前端先行**：每个里程碑都能用同一前端走完业务全流程，未就绪的后端用登记过的 Mock，再逐项替换 | 决定 61（AI 桌面）；DES-32 |
| 10 | 个性化只改“怎么说”，不改“什么是真的”；风格不得裁剪风险信息；画像不得用于评估员工 | DECISIONS 第 48 条（**助手建议，待用户确认**） |
