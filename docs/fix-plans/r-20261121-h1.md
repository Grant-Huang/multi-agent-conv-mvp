## 推荐方案与范围

1. 在高风险 `store.rs` 中先完成存在性及授权检查，再统一判断 expired/revoked；任何 view 都返回经过清空正文、摘要的 SourceUnavailable。不能仅在 HTTP 层拦截，避免运行时调用绕过。
2. 有权且状态可用时，采用 summary/source/download 精确白名单；未知值（含 raw、list、空字符串、SOURCE）返回稳定的 400 错误。缺省参数仍表示 summary。失效证据优先 410，无权仍优先 403，不通过非法参数暴露权限或存在性差异。具体内部错误表示随接口方案审批，不用通用 anyhow 错误落成 500。
3. `desktop_api.rs` 将非法视图映射为 400，不回原文/摘要。列表仍走独立 list 接口，只返回脱敏元数据；核对搜索与下载路径，确保失效内容不从其他读取入口返回。

备选是只取消未知视图返回正文，但合法/非法视图仍会产生不同的失效语义，防御也局限于单入口，不推荐。
