# 探索区

放原型、实验、调研、讨论稿这类**还没成为设计**的东西。这里的内容不约束实现，也不能当作已确认的设计引用。

| 规则 | 说明 |
|---|---|
| 写明到期日 | 每篇开头写“到期：YYYY-MM-DD”，默认一个月 |
| 到期处理 | 要么升格为特性设计（在 [DESIGN.md 第 0.3 节](../DESIGN.md#03-产品特性设计索引) 登记），要么在开头标“已归档”并写一句结论 |
| 不被引用为依据 | 设计、计划、决策不能拿探索区的内容当依据；需要时先升格 |
| 实验默认关闭 | 由探索产生的代码开关默认关闭，并在对应计划里登记 |
