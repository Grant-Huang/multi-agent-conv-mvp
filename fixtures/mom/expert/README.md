# 专家工作流（data-collection 导出）

`workflows.json` 是 data-collection（expert-collection 应用）中 9 条状态为"专家确认"的工作流图，
于 2026-11-07 从数据库只读导出，供节点绑定编译器（`crates/runtime/src/mom/binding.rs`）使用。

- 来源：3 条为员工真实口述（已同意以匿名形式用于论文发表），其中 2 条在本集合内
  （"销售订单转生产需求""来料检验（IQC）基本流程"）；01–10 场景由同事按真实工作经验编写，经专家确认。
- 只保留图结构字段：节点类型、标签、执行角色、判断问题、时限、返工语义、ICOM 对象链接（角色、名称、
  实体类型、文档类型、限定说明）和边。口述原文、证据引用、置信度、轮次 ID 均未导出。
- 已检查不含真实人名、公司名、客户名和订单号。
- 更新方式：在 data-collection 中修改并重新确认后，按同样字段重新导出；不要手工改这里的图。
